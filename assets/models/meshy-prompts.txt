# Prompts for tools/meshy-gen. One [section] per model file.
#
# A section is a slot (`tree`) or a variant of one (`tree_2`, `tree_3`…):
# every tree in the world picks one of the tree files at random, so give a
# slot several sections with different prompts and the world stops repeating
# itself. Add as many as you like. See assets/models/README.md for the slots
# and the size each is fitted to.
#
#   prompt     what to build (≤ 800 characters); indent to continue a line
#   texture    optional, guides the texturing pass separately from the shape
#   polycount  triangle budget after remesh (100–300000)
#   pose       t-pose / a-pose for characters you may rig later
#   animate    actions from Meshy's animation library (humanoids only): the
#              model is rigged and the GLB carries a clip for each; the game
#              plays them by name (idle, walk, run, crouch, jump, swim, sit)
#   height     the character's height in metres, for rigging (1.7)
#
# The reeds are instanced ~450 times in a race: keep them light.
